# Theorie – Tag 4

> **Tag 4 hat keine Pflicht-Theorie.** Diese Seite ist nur ein
> Stub, damit klar ist, wohin die Theorie-Inhalte gewandert sind.

## Warum keine Theorie an Tag 4?

V2 hat das Ziel: Lernende arbeiten **eigenständig** an Polish und
optionalen Features. Der Pflichtumfang sollte bis Ende Tag 3
fertig sein. Was übrig bleibt, ist **freie Vertiefung** – und da
hilft **kein** festes Curriculum.

## Wo ist die Theorie für Tag 4?

Statt einer Pflicht-Theorie gibt es **freiwillige Auswahl-
Kurzpräsentationen** des Trainers. Diese sind **nicht** in diesem
Lernleitfaden, sondern im **Trainer-Repo**.

Siehe [`ae-trainer-briefing`](https://github.com/HeiligerG/ae-trainer-briefing)
→ `docs/praesentationen/tag-4-kurz/`.

Themen (Auswahl):

| Slot | Thema | Dauer |
|---|---|---|
| 1 | Dark Mode | 10–15 min |
| 2 | Chart.js (Verlaufsgrafik) | 10–15 min |
| 3 | Auto-Refresh | 10–15 min |
| 4 | Animationen | 10–15 min |
| … | (Themen werden vom Trainer ergänzt) | |

**Lernende wählen selbst**, zu welchem Slot sie kommen.

## Was Lernende stattdessen tun

- Pflichtumfang polieren.
- Bugs fixen.
- Optionale Features einbauen.
- Demo vorbereiten.
