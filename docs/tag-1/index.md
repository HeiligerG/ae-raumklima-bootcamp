## Tagesziel

Am Ende des Tages hast du ein lauffähiges Dashboard-Grundlayout
– reines HTML und CSS, noch ohne JavaScript und ohne Backend.
Du hast gesehen, was eine Web-App ist, und kannst sie im Browser
anzeigen.
