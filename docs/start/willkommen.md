# Willkommen

## :material-robot-off: KI ist komplett verboten

!!! danger "Wichtigste Regel des Bootcamps"
    Du darfst während des gesamten Bootcamps **keine KI-Tools** verwenden – nicht für Fragen, nicht für Code, nicht für Erklärungen, nicht für "kleine Hilfen". Das gilt für **alle** KI-Tools:

    - ChatGPT, Claude, Gemini, Perplexity (Browser-Chatbots)
    - GitHub Copilot, Cursor, Windsurf, JetBrains AI (Code-Assistenten)
    - Jedes andere KI-Tool, das dir einfällt

    **Was stattdessen?** W3Schools, MDN, dein Trainer. Siehe [Quellen und KI-Verbot](../projekt/quellen.md).

    **Warum?** Du lernst nicht HTML, indem du KI HTML schreiben lässt. Das Selber-Machen ist der Wert dieser Woche.

## Hallo und herzlich willkommen!

Schön, dass du da bist. In den nächsten fünf Tagen baust du **alleine**
deine eigene Raumklima-Monitor-Web-App. Du arbeitest das Workbook
Schritt für Schritt durch, löst Übungen am Vorturner-Beispiel,
und am Ende hast du eine funktionierende App mit Live-Daten vom
SuvaSense-Backend.

???+ info "Das erwartet dich"
    - Du baust eine echte Web-App – von Grund auf
    - Du arbeitest **alleine** in deinem eigenen Fork
    - Du lernst HTML, CSS und JavaScript durch Abschreiben und Verstehen
    - Du bekommst 1:1-Hilfe vom Trainer bei Bedarf
    - **Keine KI** – W3Schools und DevTools sind deine Werkzeuge

## Was du brauchst

- :material-laptop: Einen Laptop (Windows, macOS oder Linux)
- :material-headphones: Kopfhörer (für Videos und Pair-Demo-Zuschauen)
- :material-notebook-outline: Etwas zum Notizen machen
- :material-coffee: Gute Laune und Geduld
- :material-microsoft-visual-studio-code: VS Code
- :material-git: Git

## Was du nicht brauchst

- :material-close: Vorkenntnisse in Programmierung – wir starten bei null
- :material-close: Spezielle Software-Lizenzen
- :material-close: Cloud-Konto oder eigener Server – das Backend läuft zentral
- :material-close: **Ein Team** – du arbeitest alleine, jeder hat sein eigenes Dashboard
